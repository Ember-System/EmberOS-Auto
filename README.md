
# EmberOS Auto

The official automotive operating system project by Ember Systems.

## About

EmberOS Auto is a standalone Linux based infotainment system designed to run directly on supported head unit hardware without requiring a connected smartphone.

## Platform

- Raspberry Pi Compute Module 5
- ARM64 Linux
- Qt 6 / QML interface
- NVMe storage

## Project Components

- EmberOS automotive interface
- Configurable home screens and widgets
- Ember Depot application store (in development)
- Local media and system settings
- Vehicle integration (planned)

## Development Status

Active development. Experimental builds are for bench testing and are not intended to replace safety-critical vehicle controls.
